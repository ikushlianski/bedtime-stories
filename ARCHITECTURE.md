# Архитектура: "Книга Гоши" v2

## Стек
- **Frontend:** HTML/JS (ридер + аннотации + diff-viewer + фидбэк)
- **Backend:** Node.js + Express
- **БД:** PostgreSQL (Neon — облако, данные не на локальной машине)
- **Агенты:** Anthropic API

---

## Агенты и модели (фиксируются для каждого запуска)

| Агент | Модель (default) | Задача |
|---|---|---|
| Сюжетник | Sonnet | Детальный план сказки |
| Психолог | Sonnet | Структурированная оценка: safety + therapeutic |
| Критик сюжетника | Haiku | Редакторская проверка плана + improvement_needed |
| Писатель | Sonnet | Финальный текст (A/B с Opus через дашборд) |
| Критик писателя | Haiku | Редакторская проверка текста + improvement_needed |
| Improver | Sonnet | Двухпроходной анализ фидбэка → правки промптов |

**Важно:** каждый запуск фиксирует модель + версию промпта для каждой роли.

---

## Структурированный вывод агентов

Все агенты возвращают JSON, не свободный текст. Это критично для надёжности конвейера.

```
// Психолог
{
  safety: {
    verdict: "safe" | "concern" | "block",
    issues: string[]
  },
  therapeutic: {
    score: 1-5,
    strengths: string[],
    gaps: string[]
  },
  recommended_changes: string[]  // actionable, конкретные
}

// Критик сюжетника / Критик писателя
{
  issues: [{ prio: "must" | "nice", description: string, quote?: string }],
  improvement_needed: boolean  // false = выход из цикла досрочно
}

// Improver
{
  patterns: [{ description: string, evidence_count: number }],
  proposed_changes: [{
    agent: string,
    current_text: string,
    proposed_text: string,
    rationale: string,
    confidence: "high" | "medium" | "low"
  }]
}
```

## Жизненный цикл

```
1. ЗАТРАВКА (ты)
   → сохраняется в банк идей

2. СЮЖЕТНИК
   → план v1

3. ИТЕРАЦИИ ПЛАНА (до 3 раз, выход досрочно если improvement_needed: false)

   Итерация 1 и финальная:
   │
   ├─ Психолог(план vN) → { safety: {verdict, issues[]}, therapeutic: {score, strengths[], gaps[]}, recommended_changes[] }
   │         ↓
   └─ Критик сюжетника(план vN + structured_psych_output) → { замечания, improvement_needed: bool }
             ↓
        Сюжетник → план v(N+1)

   Итерации 2 (промежуточные):
   └─ Критик сюжетника(план vN) → { замечания, improvement_needed: bool }
             ↓
        Сюжетник → план v(N+1)

   Психолог на итерации 1 — ловит фундаментальные проблемы рано.
   Психолог на финальной — финальное одобрение перед человеком.
   Промежуточные итерации — только критик (дешевле, быстрее).
   После 3 итераций — стоп независимо от результата.

4. ЧЕЛОВЕК СМОТРИТ НА ПЛАН
   Показывается:
   - план v1 (исходный)
   - план финальный
   - diff между ними
   - оценка психолога последней итерации
   Опционально: фидбэк на работу критика и психолога
   → одобряешь и идёшь дальше

5. ПИСАТЕЛЬ
   → текст v1

6. ИТЕРАЦИЯ ТЕКСТА (ровно 1 раз)
   │
   ├─ Психолог(текст v1)
   │    └─ психологическая оценка текста
   │         ↓
   └─ Критик писателя(текст v1 + оценка психолога)
        └─ редакторские замечания с учётом психолога
             ↓
        Писатель(замечания критика) → текст v2

7. ЧЕЛОВЕК СМОТРИТ НА ТЕКСТ
   Показывается:
   - текст v1
   - текст v2
   - diff между ними (= работа критика + психолога)
   - оценка психолога
   Опционально: фидбэк на работу критика и психолога

8. РИДЕР
   Читаешь Саше вслух
   Выделяешь текст → помечаешь реакцию (sasha_reaction | my_note)
   После: отвечаете на 1-3 вопроса от агента
   Записываешь ответы Саши кратко

9. ФИДБЭК
   Рейтинг 1-5 + текстовый комментарий

10. IMPROVER (по расписанию или после накопления 2+ фидбэков)
    Двухпроходной:
    Проход 1: читает сжатую историческую память (кластеры паттернов из всех прошлых фидбэков)
    Проход 2: читает последние 5-10 фидбэков полностью
    → кластеризует паттерны (минимум 2 сигнала для вывода)
    → предлагает точечные правки промптов с обоснованием
    Ты одобряешь каждую правку отдельно
    → промпт обновляется, старая версия сохраняется навсегда
```

## Мониторинг (детально)

### Что фиксируется для каждого запуска

Каждая сказка хранит полный снапшот на момент создания:

```
run_snapshot {
  story_id

  # Агенты и модели
  syuzhetnik_model              + prompt_version
  psychologist_plan_model       + prompt_version
  critic_syuzhetnik_model       + prompt_version
  writer_model                  + prompt_version
  psychologist_text_model       + prompt_version
  critic_writer_model           + prompt_version

  # Промежуточные результаты
  plan_iterations_count         -- сколько итераций прошло (1-3)
  plan_v1, plan_final           -- исходный и финальный план
  psychologist_plan_output      -- оценка психолога для плана
  critic_syuzhetnik_output      -- замечания критика плана
  text_v1, text_v2              -- первый и финальный текст
  psychologist_text_output      -- оценка психолога для текста
  critic_writer_output          -- замечания критика текста
}
```

### Дашборд: три панели

**Панель 1 — Динамика качества**
```
Ось X: время (по сказкам)
Ось Y: рейтинг 1-5

Слои:
- линия рейтинга
- маркеры: когда менялся промпт (какой агент)
- маркеры: когда менялась модель

Читается: после смены промпта сюжетника v3→v4 рейтинг вырос с 3.1 до 4.2?
```

**Панель 2 — Эффективность агентов**
```
Для каждого агента-критика и психолога:
- % сказок где их замечания были учтены писателем/сюжетником
- Средний diff между v1 и vFinal (большой diff = агент активно работал)
- Твой фидбэк на их работу ("помог / не помог")

Читается: психолог даёт замечания которые реально меняют план,
          или критик сюжетника игнорирует его оценку?
```

**Панель 3 — Паттерны фидбэка**
```
Improver кластеризует все твои текстовые комментарии:
- Топ-5 повторяющихся тем в критике
- Динамика: эти темы исчезают после правки промптов или остаются?

Читается: "юмор слабый" встречалось в 8 сказках до правки промпта писателя,
          и в 1 сказке после — правка сработала.
```

**Панель 4 — Реакции Саши**
```
- Аннотации по типам: sasha_reaction vs my_note
- Самые аннотированные места (где Саша реагировал чаще всего)
- Ответы Саши на вопросы: динамика вовлечённости
```

**Панель 5 — Стоимость**
```
Для каждой сказки: токены и реальный cost по каждому агенту.
Агрегированно: где деньги тратятся без видимой отдачи на качество?
Позволяет принять решение: заменить Sonnet на Haiku для конкретного агента?
```

## Что фиксируется для каждой сказки

```
story {
  id
  title
  text_final

  # Планы
  plan_v1          -- исходный план сюжетника
  plan_final       -- план после итераций с критиком
  plan_iterations  -- сколько итераций прошло

  # Тексты
  text_v1          -- первый текст писателя
  text_v2          -- после критика писателя

  # Метаданные агентов (snapshot на момент создания)
  syuzhetnik_model
  syuzhetnik_prompt_version
  critic_syuzhetnik_model
  critic_syuzhetnik_prompt_version
  writer_model
  writer_prompt_version
  critic_writer_model
  critic_writer_prompt_version

  created_at
  status: draft | ready | read | archived
  tags (JSON)                -- темы, эмоции, персонажи
  source: agent | legacy     -- agent = конвейер, legacy = из Notion
  is_legacy (boolean)
  discussion_questions (JSON)
}
```

### feedback
```
id, story_id, rating 1-5, comment
feedback_type: agent_run | retrospective
  -- agent_run: фидбэк на работу конвейера → идёт в improver
  -- retrospective: критика легаси-сказки → только аналитика, не improver
created_at
```

### prompts
```
id, agent: syuzhetnik | critic_syuzhetnik | writer | critic_writer | improver
version, text, created_at
change_reason     -- почему изменили
source_feedbacks  -- JSON: id фидбэков которые вызвали изменение
```

## Дашборд (отдельная страница)

Три блока:

**1. Динамика качества**
График рейтингов по времени. Видно: растут ли оценки после правок промптов.

**2. Тенденции в фидбэке**
Improver кластеризует твои комментарии по всем сказкам.
Например: "в 7 из 10 последних фидбэков упоминается что юмор слабый" → это сигнал.

**3. Таблица модель + промпт vs качество**

| Сказка | Дата | Модели | Версии промптов | Итераций плана | Рейтинг | Реакции Саши |
|---|---|---|---|---|---|---|

Позволяет видеть: после смены модели критика с Haiku на Opus — план стал лучше или нет? После правки промпта сюжетника v3→v4 — рейтинг вырос?

## Миграция из Notion

Отдельный скрипт: парсим Notion API → создаём записи с `is_legacy: true`, `source: legacy`.
Статус проставляется вручную при переносе: `read` если читал Саше, `ready` если нет.
Легаси-сказки можно прогнать через критика писателя — его замечания лягут в `feedback` с типом `retrospective` и будут использоваться только для аналитики, не для improver.

---

## Принципы

- **Improver не меняет промпты автоматически** — только предлагает
- **Improver не читает retrospective фидбэки** — только agent_run
- **Версии промптов не перезаписываются** — только добавляются новые
- **Каждая сказка — снапшот** модели + промпта на момент создания
- **Diff всегда показывается** — и для плана, и для текста
